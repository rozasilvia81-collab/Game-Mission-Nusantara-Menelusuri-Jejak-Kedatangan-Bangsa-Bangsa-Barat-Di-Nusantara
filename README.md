# Game-Mission-Nusantara-Menelusuri-Jejak-Kedatangan-Bangsa-Bangsa-Barat-Di-Nusantara
Mission Nusantara: Game edukasi interaktif berbasis kelompok untuk mengungkap rahasia kedatangan bangsa Barat ke Indonesia. Dirancang untuk meningkatkan keaktifan, kreativitas, kerja sama tim, serta kemampuan literasi dan numerasi siswa secara menyenangkan di kelas. Jelajahi misinya sekarang!
